## Where each set fits

- **LinkedIn:** 4, 10, 11, 13 and 14, team and trust angles for docs leaders and existing customers.
- **X:** 2, 5, 7, 9 and 17, builder-first lines.

Start with pairs 1, 3 and 6 on every platform, then move budget to the lowest cost per waitlist signup after a week. Use the hero visual as the default banner background; for pair 6, use the Review conflicts screen up close.

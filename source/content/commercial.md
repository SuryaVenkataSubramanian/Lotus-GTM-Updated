## Concept: "Two copies? Not anymore."

A fast 45-second spot built on one tension: developers live in GitHub, everyone else lives in the editor, and Lotus makes them the same docs.

| Item | Detail |
| --- | --- |
| Length | 45 seconds (hard cap 55) |
| Style | Kinetic typography over real product UI, quick cuts, the Lotus mascot as the connector |
| Structure | Problem (8s) → Two-way sync (22s) → Conflicts and publish (10s) → Tagline + CTA (5s) |
| Voice | Warm, confident narrator; short lines |
| Key outcomes | One source of truth · edit anywhere · pull requests and conflicts in the browser |
| Placement | Product Hunt gallery slot 1, X, LinkedIn, YouTube pre-roll, retargeting |

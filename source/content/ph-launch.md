## Saravana's maker comment

Post at 12:02 AM PST, the moment the launch is live. Fill the bracketed facts first.

> Hey Product Hunt, Saravana here, founder of Document360 👋
>
> For years, teams have asked us the same question: "Our docs live in GitHub. Why do we have to copy them into the knowledge base?"
>
> [Insert one real number, e.g. how many Document360 customers use the GitHub extension today, or how often it's requested.]
>
> Our GitHub extension was a start, but it only synced one way. The moment a writer fixed something in Document360, the repo was out of date again. Two copies of every doc, drifting apart.
>
> So we built Lotus.
>
> **What is it?**
> Docs as code, built into Document360. Your docs live in a GitHub repo and stay in sync with Document360 in both directions. Developers commit Markdown and review in pull requests. Writers and PMs edit in the editor. Every change lands on both sides.
>
> **Do writers have to learn Git?**
> No. They create a branch, save their changes, open a pull request and Merge & publish, all from the editor. Lotus does the Git.
>
> **What happens when both sides change the same article?**
> You see both versions side by side and choose: keep GitHub's, keep yours, or keep both. No merge markers. While someone resolves an article, it's locked so nobody overwrites them.
>
> **How hard is setup?**
> Authorize GitHub, pick any repo and branch, and Lotus checks for a small manifest called d360.json. Don't have one? We give you a prompt for Claude Code, Cursor or Codex, and your agent writes it.
>
> **We already use Document360. Can we bring our docs into Git?**
> Yes. Turn on Git Sync and choose the direction: GitHub to Document360, or Document360 to GitHub.
>
> **Why now?**
> More and more docs are written next to code, often by coding agents. Lotus lets that Markdown become a real knowledge base, without leaving the rest of the team behind.
>
> Lotus is available today in [early access / plan names]. Join the waitlist from the link above to get in early.
>
> Want to see it live? I'm walking through Lotus on [day and time]. Register here: [link]
>
> Tell us where it falls short, especially if you've lived through docs-as-code migrations. That's how it gets better.
